# Contributing

1. Create a focused branch from `main`.
2. Install both development environments as described in the README.
3. Add or update tests for behavior changes.
4. Run the backend and frontend release checks locally.
5. Open a pull request that explains the problem, solution, tests, and any privacy or security impact.

Keep generated files, credentials, browser history, and transcript exports out of commits. By contributing, you agree that your work is licensed under this repository’s MIT License.
